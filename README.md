这个平台提供了几种不同的解决方案：

**WooCommerce转应用**：电商网站的福音。产品目录、购物车、支付网关、订单管理，该有的都有，而且是原生体验。

**自定义应用**：没有网站也能用。从零开始搭建App，适合想做内容类、社区类或者工具类应用的人。

**代理白标**：给建站公司和代理商准备的，可以贴上自己的品牌，转手卖给客户。

功能方面，AppMySite提供的不只是基础的"网站套壳"。推送通知、应用内购买、多语言支持、离线模式、AdMob广告集成、社交登录——这些现代移动应用该有的功能，它都覆盖了。
